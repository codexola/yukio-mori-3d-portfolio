# 森 幸夫 | Mori Yukio — 3D Portfolio

Scroll-driven cinematic portfolio built with **Three.js** (Vite): career, skills, day/night developer life, Japan scenery, RAG/Ledger architecture diagrams, and contact.

## Run

```bash
npm install
npm run dev
```

Open the printed URL (e.g. `http://127.0.0.1:5173`).

```bash
npm run build
npm run preview
```
